# v3.3 Payroll Accuracy Audit (NHS shifts, Night Security rates, placements)

Branch `fix/v3.3-payroll-accuracy`, stacked on `release/v3.3.0-rc1` (`7f2a102`). **Not deployed.**

**Evidence available to this audit:** the source code; the real August 2026 Staffline payslip lines kept as fixtures in `Tests/Staffline_Tests.js`; and the owner's notes. **Not available:** the October payslips, the live PaySheet and the calendar. The Gmail and Drive connectors were not authenticated and `clasp` lacks permission. Every figure below says which of these it rests on.

## 1. NHS shift recognition: confirmed defect, fixed

**Before (RC):** NHS shifts were recognised only from title tokens for **06:00–14:00** ("6-2", "6am") and **14:00–22:00** ("2-10", "2pm"). **08:00–16:00 and 10:00–18:00 were never recognised.** Times written as "06:00-14:00" or "0600-1400" weren't read, and a timed event titled just "NHS Antrim" was never imported (only reported). "Causeway Hospital" or "Antrim Area Hospital" without "NHS" weren't treated as NHS.

**Now (`CalendarService.classifyNhsEvent`):**
- **Both hospitals.** The title contains "NHS" or "HSC" (as before), "Antrim Hospital", "Antrim Area Hospital" or "Causeway Hospital". "Coleraine" or "Causeway" *alone* is deliberately **not** NHS, because the council warden jobs use those names.
- **The shift window comes from the title** in any common format: 6-2, 8-4, 10-6, 2-10, 06:00-14:00, 0800-1600, 8am-4pm, 10:00–18:00 (en-dash), "8 to 4", 14:00 - 22:00. 12-hour shorthand is read the way NHS shifts run.
- **Otherwise from the event's own start and end** (timed, same-day, on the hour). This is skipped when the title names another role ("NHS Coleraine security") or states a different time ("NHS 9am"); those stay *reported, not guessed*. All-day events with no time stay unrecognised.
- **Only the four windows are paid.** Anything else (e.g. 07:00–15:00) is left for review.

| Window | Weekday | Saturday | Sunday |
|---|---|---|---|
| 06:00–14:00 | NHS 6am-2pm Basic **£95.33** | NHS Saturday **£134.40** | NHS Sunday **£174.45** |
| 08:00–16:00 | Basic **£95.33** | £134.40 | £174.45 |
| 10:00–18:00 | Basic **£95.33** | £134.40 | £174.45 |
| 14:00–22:00 | NHS 2pm-10pm Split **£105.75** | £134.40 | £174.45 |

Basis, verified on real payslips: every NHS shift is 8h with a 30-minute unpaid break, i.e. **7.5 paid hours** (Aug payslip, N621137: 28 basic + 9.5 unsocial = 37.5h for 5 shifts).
- 7.5 × £12.71 = £95.33.
- The 14–22 split is 5.5h basic + **2h unsocial (20:00–22:00) at £17.92** = £69.91 + £35.84 = £105.75. The unsocial rate is unchanged.
- Saturday and Sunday pay every window at the Saturday/Sunday rate, as the existing rules did.
- No new shift types are needed: 08–16 and 10–18 use the existing NHS **Basic** type, as the payslip does.

Hospital identity is kept on the Calendar Sync Record (event title). Calendar colours are not read or changed anywhere in Pay Tracker, so nothing alters them.

## 2. Night Security rates: one defect confirmed and fixed; the £20.87 rate not verified

**Verified against the August 2026 payslip:** Staffline pays Night Security (N621105, N624148) **Enhanced 1.33 at £17.92** and **Enhanced 1.50 at £20.21**. Pay Tracker had **£17.91** for ×1.33: £13.47 × 1.33 = £17.9151, which Staffline rounds to £17.92. So every Night ×1.33 hour was 1p short.

Fixed in `Config.js`: Night Security Enhanced 1.33 and Overtime 1.33 → **£17.92**. Every other Night and Relief rate already equals base × multiplier rounded to the penny (checked one by one).

The 4-hour **fixed** amounts (used only when a row has no hours) were computed from unrounded rates. They now equal 4 × the paid rate, as the payslip does (e.g. Night 1.50: **£80.84**, as on the payslip, not £80.82).

**£20.87 for Enhanced 1.50: NOT verified, NOT applied.** No October payslip was available, and the only payslip evidence (August) shows £20.21. £20.87 / 1.5 = £13.913, which would imply the Night basic rose from £13.47 to about **£13.91**, and so likely every Night rate (×1.33 → about £18.50). That shouldn't be assumed. To apply it safely Pay Tracker needs, from the payslip: **the first week ending at the new rate, and the Basic, Enhanced 1.20, 1.33, 1.50 and 2.00 rates.** With those, the rates become effective-dated so earlier weeks keep £20.21.

**Historical rows on the first sync after deploying:** Night ×1.33 rows that Calendar wrote and nobody changed are recalculated at £17.92 (+1p/hour, matching what Staffline actually paid). Rows you corrected by hand are kept (v3.3 manual-correction rule). Other rows don't change.

## 3. Separate NHS placements: confirmed defects in reconciliation, fixed; no combined overtime exists
- **Overtime:** nothing in Pay Tracker calculates overtime automatically. The HSC/Overtime shift types are only ever chosen by hand, so **no combined-placement overtime existed, and none was added.** The August payslip confirms overtime is per timesheet (N624186 alone: 45h → 7.5h HSC Overtime).
- **Defect 1, fixed:** Staffline reconciliation compared each NHS timesheet with **all** NHS calendar shifts, because both hospitals are one job (`JOB-NHS`). With an Antrim and a Causeway timesheet in the same week, each showed a false "Hours Differ". Each timesheet is now compared only with its own hospital's shifts, using the timesheet's Work Address/Placement and the shift's title. A side that names no hospital still matches, so no hours are hidden. "Missing from Staffline" is now worked out per hospital too.
- **Defect 2, fixed:** NHS calendar rows store no hours (pay is by shift type), so reconciliation counted **0 calendar hours** for every NHS shift. It now counts 7.5 paid hours per NHS shift.
- **Combined reporting is unchanged:** payslip totals and overall income still include both placements.

|---|---:|---:|
| Reported difference | £100.59 | £100.59 |
| Missing NHS shift, now imported | 7 Oct Antrim 10:00–18:00 (Wed): **+£95.33** | 15 Oct Antrim 08:00–16:00 (Thu): **+£95.33** |
| **Remaining, unexplained** | **£5.26** | **£5.26** |

- Both missing shifts were 10–18 or 8–16 windows, which the RC couldn't recognise (verified in tests on the RC code). Both import as 7.5h Basic = £95.33.
- **Likely cause of the remaining £5.26 a week (not verified):** it is within 2p of **8 hours × £0.66** (£5.28), the reported Night Security ×1.50 increase (£20.87 − £20.21). Any ×1.33 Night hours would reduce it slightly (+1p/hour now fixed). Confirming it needs the two payslips' Night Security lines.
- These are two separate NHS placements whose earnings appear on one payslip. Nothing here treats the combined total as an overtime threshold.
