## 1. National Living Wage (21 and over)

| Date | Minimum | Source |

- Pay rules in the release (`PAY_RULES`):

| Table | Basic hourly | Above minimum from 1 Apr 2026? |

- **Logging Cash £10/hr is kept but not checked automatically.** Its classification (hourly employment rate, cash-earnings category, or fixed logging payment) is unverified, so the minimum-wage check does not apply to it until the owner classifies it (`UNVERIFIED_CLASSIFICATION`).
- **NHS basic (£12.71) is undated in the code.** The repository history shows no earlier NHS basic value, so there is no evidence of a rate change in code. Before 1 April 2026 the contract may have paid £12.21 (or other). Because the rate is undated, any pre-April shift priced with the current code is priced at £12.71. The owner must confirm the pre-April NHS basic rate against Staffline payslips. This needs a dated entry, not a change to history.

## 2. Seasonal contracts ended 31 October 2026

- **Night Security Warden** and **Relief Assistant Warden**: contract end 31 October 2026, recorded in `PayTrackerEmploymentPeriods.JOB_PERIODS`.
- Forecasting of future regular shifts stops after 31 October for these jobs (`forecastAllowed`). Existing shifts, payslips and history are kept. Jobs are kept for reactivation: a new period is added, and earlier periods are never deleted.
- **Wired (651960c):** the calendar sync does not write a Night Security or Relief shift dated after 31 Oct 2026. It returns `flaggedAfterContractEnd`, counted in the sync summary, and changes no PaySheet or Calendar Sync Record. Existing shifts keep their pay. The take-home forecast averages existing weeks only, so it adds no future earnings for these jobs.
- **Still open:** flagged shifts appear only in the sync summary. A durable Action Centre entry needs an approved write path.
- Late final payments, outstanding adjustments and holiday pay are recordable after the end date (`recordingAllowed`). Nothing is gated for pay already earned.
- **NHS Car Parking Assistant** (`JOB-NHS`) has no periods and is unaffected.
